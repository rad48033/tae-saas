# TAE SaaS Monorepo

3개의 마이크로 SaaS 통합 코드베이스.

## Apps
- `apps/pdf-api` - PDF to JSON 변환 API
- `apps/youtube-blog` - YouTube 영상 to 블로그 변환
- `apps/readme-bot` - GitHub README 자동 생성

## Packages
- `packages/db` - Supabase 클라이언트
- `packages/ai` - Claude API 래퍼
- `packages/stripe` - LemonSqueezy 결제 로직
- `packages/ui` - 공통 UI 컴포넌트
